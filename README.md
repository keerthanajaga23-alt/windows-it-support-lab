# Windows IT Support Lab

## Overview

This repository contains hands-on Windows IT Support labs and troubleshooting exercises.

The goal of this project is to develop practical skills required for an entry-level IT Support / Desktop Support / Service Desk role.

## Skills Covered

* Windows user account administration
* Local user and group management
* Administrator privileges
* User access management
* Account and login troubleshooting
* Windows troubleshooting
* System administration
* Incident troubleshooting and documentation

## Lab Environment

* Windows client operating system
* Local test user accounts
* Windows administrative tools
* Command Prompt
* Windows Settings
* Local Users and Groups

## Project Structure

### 01 - User Account Administration

Creating, inspecting, enabling, disabling and managing Windows user accounts.

### 02 - Groups and Administration

Managing local groups and understanding standard user versus administrator privileges.

### 03 - Account and Login Troubleshooting

Troubleshooting common login, password, disabled-account and account-lockout problems.

### 04 - Mini Windows IT Support Project

Combining account administration and troubleshooting into realistic IT Support scenarios.

## Troubleshooting Approach

For each issue, I follow a structured troubleshooting process:

1. Identify the problem
2. Gather information
3. Check the most likely causes
4. Perform troubleshooting
5. Apply the appropriate resolution
6. Verify the solution
7. Document the incident

## Objective

Build practical Windows IT Support experience through hands-on labs, troubleshooting scenarios and technical documentation.
