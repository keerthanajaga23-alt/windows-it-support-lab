# Windows User Account Administration

## Objective

Practice basic Windows user account administration using local test accounts.

## Tasks Completed

* Created local test user accounts
* Inspected user account information
* Enabled and disabled accounts
* Checked account status
* Practiced password administration
* Used Windows administrative tools
* Used Command Prompt for account administration

## Test Accounts

The lab uses temporary test accounts created specifically for practice.

> No real user accounts or personal information are included in this repository.

## Tools Used

* Windows Settings
* Local Users and Groups
* Command Prompt
* `net user`
* `whoami`

## Troubleshooting Practice

I practiced identifying account-related problems such as:

* Disabled user account
* Incorrect password
* Account status problems
* User unable to log in

## Key Learning

User account administration is an important part of first-level IT Support. Before changing an account, the support engineer should verify the user's identity, understand the problem and check the account status.

## Verification

After making changes, I verified that the test account could perform the expected action.

## Skills Demonstrated

* Windows account administration
* Basic command-line administration
* Account troubleshooting
* Verification
* Technical documentation
